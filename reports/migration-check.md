# 整理与迁移验收

验收日期：2026-10-07。验证平台为同一台 Windows x64 机器，但使用独立项目目录、从零创建的两个虚拟环境，以及完整依赖约束安装。没有复制旧虚拟环境，也没有复制 Hugging Face 登录 token。这验证了不同路径与新环境重建；其他实体电脑仍需安装 Python 3.9 和正常图形驱动。

## 核心实验

- Windows PowerShell 5.1 安装脚本成功创建 Python 3.9 环境，依赖检查通过。
- 2 个迁移测试通过，Python 编译与 PowerShell 语法检查通过。
- 环境 smoke test 全部通过：LunarLander reset/step/render、16 环境、Shimmy、MuJoCo 物理及渲染。
- 不登录账号，匿名下载已发布模型的固定提交成功；模型 SHA-256 与原始本地模型一致。
- 下载模型的 10 局确定性评分为 **229.74 ± 16.79**，每局分数和步数与原实验完全一致；视频为 395 帧，有运动像素变化。
- 从头重跑一键完整训练，16 个子进程，请求 1,000,000 步，实际 1,015,808 步，耗时约 245.26 秒。
- 重新训练后的 10 局分数及步数与原实验完全一致，仍为 **229.74 ± 16.79**。
- 模型打包、训练曲线、原始曲线重绘及运行汇总成功。
- Shimmy 旧模型重评估为 **302.04 ± 18.39**，每局结果与原实验一致。
- Genesis 独立环境从零安装和依赖检查通过，CPU 100 步重力及碰撞验收通过，最终盒子高度 **0.099892 米**，与原始验收一致。
